# Public test inputs and evidence

Synth2 tests use self-authored patch/MIDI/signal inputs and product API or
mathematical expectations. Temporary WAV/ZIP/state data is created by the tests.
No external patch bank is bundled; bank fixtures are generated by tests. No recorded
original-engine PCM, clock/RNG trace, expected-control corpus or old state archive
is needed to build or execute these tests.

A filter's signal properties and a state round trip's submitted values can be
verified directly. An implementation-to-implementation comparison establishes
regression preservation under its inputs; it does not independently establish
original-instrument correctness. Do not generate a supposed independent oracle
from the changed implementation or relax a bound to conceal a difference.

See [public tests](../tests/README.md), [validation](contracts/validation.md) and
[publication preparation](publication/README.md). Historical asset distribution and history publication remain separate decisions;
tree cleanup does not erase history.
